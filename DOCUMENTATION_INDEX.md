## 📋 Content at a Glance

### API Methods (Most Important)

```javascript
// Show content loading
Loading.showContentLoading(container, message, size)

// Hide content loading
Loading.hideContentLoading(container)

// Show skeleton
Loading.showSkeleton(container, skeletonType)

// Hide skeleton
Loading.hideSkeleton(container)
```

### Skeleton Types
- `'table'` - Table rows (6 rows)
- `'metric-grid'` - 4 metric cards
- `'metric-card'` - Single metric
- `'chart-card'` - Chart placeholder
- `'list'` - List items (5 items)
- `'form'` - Form fields
- `'modal'` - Modal content

### Spinner Sizes
- `'sm'` - Small (20px) - Cards, badges
- `'md'` - Medium (28px) - Default centers
- `'lg'` - Large (40px) - Content area (recommended)
- `'xl'` - Extra Large (56px) - Full sections
